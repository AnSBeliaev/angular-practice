# План: Angular для разработчика React

Опыт: 4 года React. Срок плотного погружения: 3–4 недели при 2–3 часах в день, или 2–2,5 недели полный день.

JavaScript, TypeScript, DOM и устройство SPA заново не учим. Меняется модель: долгоживущий класс и шаблон вместо функции, которая каждый раз возвращает разметку, плюс встроенные DI, роутер и формы.

Стек учебного проекта: **Angular 22** (сейчас 22.3), standalone-компоненты, zoneless. Документация: [angular.dev](https://angular.dev). Туториалы 2021–2023 годов с `NgModule`, `*ngIf` и толстыми конструкторами нужны, чтобы узнавать их в чужом коде, а не чтобы писать с нуля.

## Пять сдвигов

1. Экземпляр компонента создаётся один раз и живёт, пока компонент на странице. Поля класса не сбрасываются между обновлениями экрана.
2. Присваивание обычного поля экран не обновляет. UI двигают сигнал, прочитанный в шаблоне, `AsyncPipe`, событие шаблона или `markForCheck`.
3. Сигнал уведомляет только о `.set()` и `.update()`. Мутация объекта внутри сигнала проходит молча.
4. `inject()` вызывается в injection context: поле класса, конструктор, фабрика. В обработчике клика и внутри `subscribe` его вызывать нельзя.
5. `HttpClient` холодный: каждая подписка — новый запрос. Для чтения данных используем `httpResource`. Мутации — через `HttpClient`.

## Маппинг React → Angular 22

| Задача | React | Angular 22 |
|---|---|---|
| Компонент | Функция + JSX | Класс, `@Component`, HTML-шаблон |
| Состояние | `useState` | `signal`, `.set()`, `.update()`, `asReadonly()` |
| Производные данные | `useMemo` | `computed` |
| Состояние, сбрасываемое от пропса | `useState` + `useEffect` | `linkedSignal` |
| Эффект | `useEffect` | `effect` — только синхронизация с внешним миром |
| Пропсы и события | props, колбэки | `input()`, `output()` |
| Двусторонняя связь | value + onChange | `model()` и `[(prop)]` |
| Слоты | `children` | `ng-content`, при необходимости `ng-template` |
| Контекст | `useContext` | Сервис + `inject()`, иерархия инжекторов |
| Чтение с сервера | TanStack Query | `httpResource` |
| Мутации и нетиповой HTTP | Axios | `HttpClient`, функциональные interceptors |
| Потоки событий | промисы, иногда RxJS | Observable: `switchMap`, `debounceTime`, `async`-пайп, `toSignal`, `takeUntilDestroyed` |
| Роутинг | React Router | `@angular/router`, `loadComponent`, функциональные guards, query params |
| Новые формы | React Hook Form + Zod | Signal Forms: `form()` из `@angular/forms/signals` |
| Формы в существующих проектах | — | Reactive Forms: `FormGroup`, `FormArray`, `valueChanges` |
| Крупный стор | Redux / Zustand | Сервис на сигналах, дальше NgRx SignalStore |

`effect` не используем, чтобы пересчитать значение. Для этого есть `computed` и `linkedSignal`.

## Неделя 1. Компонент, шаблон, сигналы

Цель: собрать экран из standalone-компонентов, у которых состояние и производные значения — сигналы.

Материалы: [Essentials](https://angular.dev/essentials), [туториал по сигналам](https://angular.dev/tutorials/signals).

- [x] Поднять приложение через `ng new`. Посмотреть `bootstrapApplication`, `app.config.ts`, корневой компонент. `zone.js` в зависимостях нет.
- [x] Счётчик: `signal`, `computed`, `.update()`, `.set()`, вывод через `{{ }}`, событие через `(click)`.
- [x] Шаблон: `[prop]`, `(event)`, `@if`, `@for` (с `track`), `@switch`, `@let`. Классы и стили через `class` и `style`.
- [x] Публичный API компонента: `input()` / `input.required()`, `output()`, `model()`, проекция через `ng-content`.
- [x] `linkedSignal` и `asReadonly()`.

Упражнение: список с фильтром. Поле поиска — сигнал, отфильтрованный список — `computed`, выбранный id сбрасывается через `linkedSignal`, когда фильтр выкидывает текущий элемент. Отдельная кнопка мутирует объект внутри сигнала и не обновляет экран, пока нет `.set()`.

Готово, когда новый компонент создаётся через CLI, импортируется в `imports` родителя и не требует модуля.

## Неделя 2. Сервисы, DI, почему обновляется экран

Цель: выносить состояние через иерархию инжекторов.

- [ ] Синглтон: `@Service()` и `@Injectable({ providedIn: 'root' })`. Внедрение через `inject(Token)` в поле класса.
- [ ] Провайдер на компоненте и на роуте. Дочерние компоненты видят экземпляр, соседи за границей — нет.
- [ ] Сервис-состояние: приватный `signal`, публичный readonly, команды-методы, производные через `computed`.
- [ ] Прочитать [гайд про zoneless](https://angular.dev/guide/zoneless). Сломать экран: обновить обычное поле после `setTimeout` и после `Promise`, починить записью в сигнал.

Упражнение: корзина в сервисе ([шаг туториала](https://angular.dev/tutorials/signals/7-using-signals-with-services)). Тот же сервис, предоставленный на компоненте маршрута, даёт изолированную корзину на двух страницах. Корневой синглтон — одну общую.

Готово, когда понятно, какой инжектор создаст экземпляр и кто его увидит.

## Неделя 3. Данные, RxJS по минимуму, роутер

Цель: список, карточка и мутация с отменой устаревшего запроса, охраной маршрута и токеном в заголовке.

Операторы, которых хватает на старт: `map`, `filter`, `tap`, `switchMap`, `debounceTime`, `catchError`, `combineLatest`. Плюс cold/hot и пара `Subject` / `BehaviorSubject`.

- [ ] Чтение через `httpResource(() => url)`. Зависимость от сигнала перезапускает запрос и отменяет предыдущий. Мутации (`POST` / `PUT` / `DELETE`) — через `HttpClient`.
- [ ] Подписки: в шаблоне `async`-пайп, в классе `toSignal()` или `takeUntilDestroyed()`.
- [ ] Функциональные interceptors: токен и редирект на 401. Подключение через `provideHttpClient(withInterceptors([...]))`.
- [ ] Роутер: `loadComponent`, `CanActivateFn`, параметры маршрута в `input()`. Фильтры списка держать в query params.

Упражнение: поиск с `debounceTime` + `switchMap` (или `httpResource` от сигнала запроса). Быстрый ввод оставляет на экране ответ последнего запроса.

Готово, когда список не делает два одинаковых GET из-за двух подписок и старый ответ не затирает новый.

## Неделя 4. Формы, легаси и один вертикальный срез

Цель: собрать форму и читать файл со `*ngIf`, не останавливаясь.

- [ ] [Signal Forms](https://angular.dev/guide/forms/signals/overview): модель-сигнал, `form()`, схема (`required`, `email`, кросс-поле), директива `FormField`. Динамический список полей и проверка, которая смотрит на два поля сразу.
- [ ] Reactive Forms, потому что в рабочих репозиториях они ещё основной диалект: типизированный `FormGroup`, `FormControl`, `FormArray`, `valueChanges`, async-валидатор, показ ошибки после touch.
- [ ] Полдня на чтение легаси: `@NgModule`, `declarations` / `imports` / `exports`, `*ngIf` / `*ngFor`, `@Input()` / `@Output()`, DI через параметры конструктора, `zone.js`.

Пет-проект в этом репозитории:

- [ ] Логин и сессия в сервисе на сигналах.
- [ ] Функциональный interceptor и guard.
- [ ] Таблица с фильтром и пагинацией в query params и `httpResource`.
- [ ] Карточка с ленивым роутом.
- [ ] Форма создания и редактирования на Signal Forms, с массивом вложенных полей.
- [ ] Удаление через `HttpClient`, после успеха список обновляется.

Критерий: сценарий проходит в браузере от логина до сохранённой записи, обновление страницы восстанавливает фильтры из URL, уход со страницы не оставляет висящих подписок.

## Если проект окажется на Angular 15–17

Синтаксис шаблонов и сигналы всё равно учить в современном виде: в поддерживаемых версиях они уже есть. Поменять акцент недели 4: Reactive Forms и модули раньше, Signal Forms оставить обзором на один вечер.

## В первый месяц не учить

Внутренности Zone.js, SSR и hydration, кастомный `ControlValueAccessor`, авторство `NgModule`, полный каталог RxJS, классический NgRx с actions, reducers и effects. Это точечные темы под конкретный проект.
